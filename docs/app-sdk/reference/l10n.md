# `l10n`

## `locale`

```rust
pub fn locale() -> String
```

The locale of the phone's UI text: always `en_US`.

## `common`

```rust
pub fn common(key: &str) -> String
```

The phone's text for a common word:

| Key | Text | Key | Text |
| --- | --- | --- | --- |
| `ok` | OK | `no` | No |
| `cancel` | Cancel | `more` | More |
| `back` | Back | `delete` | Delete |
| `exit` | Exit | `save` | Save |
| `select` | Select | `loading` | Loading... |
| `yes` | Yes | `error` | Error |

Any other key is returned unchanged.

## `format_time`

```rust
pub fn format_time(unix: u64, style: TimeStyle) -> String

pub enum TimeStyle { Time, Date, DateAndTime }
```

Formats `unix`, in seconds since the Unix epoch, in the phone's time zone:

| `style` | Result | Example |
| --- | --- | --- |
| `TimeStyle::Time` | The time. | `4:05 PM`, or `16:05` with a 24-hour time format. |
| `TimeStyle::Date` | The date. | `Nov 13, 2026` |
| `TimeStyle::DateAndTime` | The date and the time. | `Nov 13, 2026 4:05 PM` |

Month names are English abbreviations, and the order of the date is fixed.  The phone's date format setting doesn't apply, here or on the phone's screens.

## `utc_offset`

```rust
pub fn utc_offset() -> i32
```

The current offset of the phone's local time from UTC, in seconds; positive east of UTC.
