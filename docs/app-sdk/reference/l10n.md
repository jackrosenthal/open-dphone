# `l10n`

The locale, common words, and the text of dates and times.  Capability `l10n`.

## `locale`

```rust
pub fn locale() -> String
```

The locale of the phone's texts.  The result is always `en_US`.

## `common`

```rust
pub fn common(key: &str) -> String
```

The phone's text for a common word, for labels that match the phone's screens:

| Key | Text | Key | Text |
| --- | --- | --- | --- |
| `ok` | OK | `no` | No |
| `cancel` | Cancel | `more` | More |
| `back` | Back | `delete` | Delete |
| `exit` | Exit | `save` | Save |
| `select` | Select | `loading` | Loading... |
| `yes` | Yes | `error` | Error |

Any other key is returned unchanged.

## `format_time`

```rust
pub fn format_time(unix: u64, style: u8) -> String
```

WIT name: `format-time`.

The text of a time in the phone's time zone.  `unix` is seconds since the Unix epoch, e.g., from [`timers::wall_time`](timers.md#wall_time).

| `style` | Result | Example |
| --- | --- | --- |
| 0 | The time. | `4:05 PM`, or `16:05` when the phone's time format is a 24-hour format. |
| 1 | The date. | `Nov 13, 2026` |
| 2 or more | The date and the time. | `Nov 13, 2026 4:05 PM` |

The month names are English abbreviations and the order of the date is fixed; the phone's date format setting is not applied.

## `utc_offset`

```rust
pub fn utc_offset() -> i32
```

WIT name: `utc-offset`.

The offset of the phone's local time from UTC at this moment, in seconds, for the phone's time zone; east of UTC is positive.
