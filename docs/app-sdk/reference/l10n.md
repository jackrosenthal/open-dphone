# `l10n`

The locale, common UI strings, and date and time formatting.

## `locale`

```rust
pub fn locale() -> String
```

Returns the locale of the phone's UI text.  The result is always `en_US`.

## `common`

```rust
pub fn common(key: &str) -> String
```

Returns the phone's text for a common word, so that an app's labels match the phone's screens:

| Key | Text | Key | Text |
| --- | --- | --- | --- |
| `ok` | OK | `no` | No |
| `cancel` | Cancel | `more` | More |
| `back` | Back | `delete` | Delete |
| `exit` | Exit | `save` | Save |
| `select` | Select | `loading` | Loading... |
| `yes` | Yes | `error` | Error |

Any other key is returned unchanged.

## `format_time`

```rust
pub fn format_time(unix: u64, style: TimeStyle) -> String

pub enum TimeStyle { Time, Date, DateAndTime }
```

Formats a time in the phone's time zone.  `unix` is in seconds since the Unix epoch, such as a value from [`timers::wall_time`](timers.md#wall_time).  `TimeStyle` is in the SDK's prelude.

| `style` | Result | Example |
| --- | --- | --- |
| `TimeStyle::Time` | The time. | `4:05 PM`, or `16:05` if the phone is set to a 24-hour time format. |
| `TimeStyle::Date` | The date. | `Nov 13, 2026` |
| `TimeStyle::DateAndTime` | The date and the time. | `Nov 13, 2026 4:05 PM` |

Month names are English abbreviations, and the order of the date is fixed.  The phone's date format setting is not applied, either here or on the phone's screens.

## `utc_offset`

```rust
pub fn utc_offset() -> i32
```

Returns the current offset of the phone's local time from UTC, in seconds, for the phone's time zone.  Offsets east of UTC are positive.
