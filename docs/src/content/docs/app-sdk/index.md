---
title: "App SDK"
---

An Open Desk Phone app is a WebAssembly component that targets the `app` world of [`app.wit`](https://github.com/jackrosenthal/opendeskphone/blob/main/crates/opendeskphone-app-sdk/wit/app.wit) and holds the app's manifest in a `opendeskphone-app` custom section.  The `opendeskphone-app-sdk` crate provides both in Rust.
