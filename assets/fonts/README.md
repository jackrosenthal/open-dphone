# Fonts

- `Roboto-*.ttf` (Regular, Medium, Bold, Light, Thin): Roboto 3.016 from the upstream release (as packaged by Arch Linux `ttf-roboto`), SIL Open Font License 1.1 (`LICENSE-Roboto-OFL.txt`).  Used by the color skin.
- `bitmap/helv*.bdf`: the Adobe Helvetica bitmap fonts of the X.Org font collection, with Markus Kuhn's ISO 10646-1 extension, unmodified: `helvR08`, `helvR10`, `helvB10`, `helvR12`, `helvB12`, `helvB18`, and `helvB24` from `font-adobe-75dpi` 1.0.4 (<https://gitlab.freedesktop.org/xorg/font/adobe-75dpi>, commit `6189f2a`), and `helvB24` from `font-adobe-100dpi` 1.0.4 (<https://gitlab.freedesktop.org/xorg/font/adobe-100dpi>, commit `13f867e`); the file names carry the resolution.  Copyright Adobe Systems and Digital Equipment Corporation; a permissive license (copy, modify, distribute, and sell, with the notice kept: `bitmap/LICENSE-Adobe-Helvetica.txt`, also at the head of each file).  Used by the gray skins for all text.
- `bitmap/6x10.bdf`, `bitmap/6x13.bdf`: the "misc-fixed" fonts from `font-misc-misc` 1.1.3 (<https://gitlab.freedesktop.org/xorg/font/misc-misc>, commit `c4e2af0`), unmodified.  Public domain (`bitmap/LICENSE-misc-fixed.txt`).  Used by the gray skins for the characters Helvetica lacks (Greek, Cyrillic, and more), and for the replacement character.

`crates/dphone-ui/build.rs` rasterizes the TrueType fonts into glyph atlases and converts the bitmap fonts into glyph tables at build time; the font files themselves are not shipped on the phone.
